## 🎯 Возможности

### Настройка игрового прицела

- Независимая настройка перекрестия и центральной точки.
- Регулировка размера элементов.
- Настройка цвета и прозрачности.
- Возможность отдельно включать и отключать перекрестие и центральную точку.
- Три формы центральной точки:
  - круг;
  - квадрат;
  - крест.
- Автоматическое сохранение настроек.

### Игровой предпросмотр

В приложение встроена область предпросмотра на основе изображения STALZONE.

Все изменения прицела отображаются непосредственно поверх игрового изображения в реальном времени.

Предпросмотр не зависит от состояния игрового оверлея, поэтому настраивать прицел можно даже при закрытой игре.

### Управление отображением

- Управление видимостью прицела.
- Скрытие прицела при удержании ПКМ.
- Автоматическое определение STALZONE.
- Автоматическое отображение и скрытие игрового оверлея в зависимости от активности игры.

## ☢️ Поддержка STALZONE

POLYCRHAIR поддерживает автоматическое обнаружение игрового окна STALZONE.

При включённом автоматическом режиме приложение:

1. Определяет запущенную игру.
2. Отслеживает активность игрового окна.
3. Позиционирует прицел относительно игровой области.
4. Показывает прицел при возвращении в игру.
5. Скрывает игровой оверлей при переключении на рабочий стол или другое приложение.
6. Скрывает игровой оверлей после закрытия игры.

### Поддерживаемые режимы

| Режим | Статус |
|---|---|
| Оконный | Работает |
| Окно без рамки | Не гарантируется |
| Полноэкранный | Не гарантируется |
| Окно без рамки (режим совместимости) | Проверен, работает |

**Важно:** отображение поверх обычного Borderless и Exclusive Fullscreen пока не реализовано. Для стабильной работы со STALZONE рекомендуется использовать режим «Окно без рамки (режим совместимости)».

## 📺 Интеграция с OBS Studio

POLYCRHAIR поддерживает интеграцию с OBS Studio через OBS WebSocket.

Возможности:

- Подключение к OBS Studio.
- Получение списка сцен.
- Выбор сцены для добавления прицела.
- Автоматическое создание Browser Source.
- Автоматическая адаптация источника под разрешение холста OBS.
- Центрирование источника.
- Независимое управление видимостью игрового прицела и трансляционного источника.

Для работы интеграции необходимо включить OBS WebSocket в настройках OBS Studio и указать параметры подключения в приложении.

Трансляционный прицел продолжает работать независимо от скрытия игрового оверлея.

## 📥 Установка и запуск

### Portable-версия

Основной вариант распространения — самостоятельный исполняемый файл `POLYCRHAIR.exe`.

Преимущества:

- Не требуется устанавливать Python.
- Не требуется запускать установщик.
- Не требуется отдельно устанавливать библиотеки.
- Приложение запускается непосредственно из EXE.

**Запуск:**

1. Скачайте `POLYCRHAIR.exe` из раздела Releases.
2. Поместите файл в удобную папку.
3. Запустите двойным щелчком мыши.

Настройки и профили сохраняются отдельно от EXE.

## 🛠️ Сборка из исходного кода

### Требования

- Windows 10 / Windows 11.
- Python.
- pip.
- PyInstaller.

### 1. Клонирование репозитория

```bash
git clone https://github.com/PLUS4A666/crosshair-by-polyushkovplay.git

cd crosshair-by-polyushkovplay
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

Активация:

```bash
.venv\Scripts\activate
```

### 3. Установка зависимостей

```bash
python -m pip install --upgrade pip

python -m pip install -r requirements.txt

python -m pip install pyinstaller
```

### 4. Запуск из исходного кода

```bash
python crosshair.py
```

### 5. Сборка Portable EXE

```bash
python -m PyInstaller --noconfirm --clean --windowed --onefile --name POLYCRHAIR --add-data "assets;assets" --collect-all PyQt5 --collect-all obsws_python crosshair.py
```

После завершения сборки готовый файл появится здесь:

```text
dist/
└── POLYCRHAIR.exe
```

## ⚠️ Известные ограничения

- Работа в обычном Borderless и Exclusive Fullscreen не гарантируется.
- Для STALZONE рекомендуется режим окна без рамки с режимом совместимости.
- Для автоматической интеграции с OBS требуется работающий OBS WebSocket.
- Совместимость с другими играми не гарантируется.
- Работа на Windows 10 и Windows 11 предполагается, но проверка проведена не на всех конфигурациях.
